# PERCEPTA

Juego de puzzles basado en percepción y perspectiva forzada inspirado en Superliminal.

## Cómo ejecutar

Abrir `index.html` en un navegador moderno (Chrome, Firefox, Edge).

## Controles

| Tecla | Acción |
|-------|--------|
| W/A/S/D | Movimiento |
| Mouse | Mirar alrededor |
| Click | Interactuar / Soltar objeto |
| E | Recoger objeto |
| ESC | Pausa / Menú |
